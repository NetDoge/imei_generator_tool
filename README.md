# IMEI 工具使用说明

> 本程序不提供 IMEI,使用者需要自行导入 IMEI 前缀来进行生成。
> **合规提示**:本工具仅供软件开发测试、学习研究等合法用途。在多数国家和
> 地区,伪造、篡改或克隆真实设备的 IMEI 属于违法行为,请勿用于任何真实设备。

## 介绍

这是一个用 C 语言编写的 IMEI 处理工具,支持以下功能:

1. 导入 IMEI 前缀及对应设备型号
2. 列出已导入的前缀(交互模式分页显示)
3. 根据前缀生成随机的 IMEI(库中无前缀时,自动合成前 2 位为真实国家码的随机前缀)
4. 验证 IMEI 是否有效

数据存在本地 SQLite 数据库(`imei.db`)中。

## 安装与编译

### 下载预编译版本(推荐)

从 [Releases](https://github.com/NetDoge/imei_generator_tool/releases) 下载对应平台的压缩包,内含二进制、README、LICENSE 和示例 CSV:

| 平台 | 文件 |
|---|---|
| Linux x86-64 | `imei-tool-linux-amd64.tar.gz` |
| Linux ARM64 | `imei-tool-linux-arm64.tar.gz` |
| Linux armv7 | `imei-tool-linux-armv7l.tar.gz` |
| Linux 32 位 x86 | `imei-tool-linux-386.tar.gz` |
| Windows x86-64 | `imei-tool-windows-amd64.zip` |
| Windows 32 位 | `imei-tool-windows-386.zip` |
| macOS Intel | `imei-tool-darwin-amd64.tar.gz` |
| macOS Apple Silicon | `imei-tool-darwin-arm64.tar.gz` |

- Linux 版为静态编译,不依赖系统 libsqlite3,任何发行版解压即用
- Windows 版为 mingw 交叉编译,命令行直接运行(交互菜单需在终端中使用)
- Windows 中文乱码已修复(v1.0.1):程序启动时自动把控制台切到 UTF-8 代码页,
  无需手动执行 `chcp 65001`;中文路径/型号参数与 CSV 导入同样不乱码
- 下载后可用附件 `SHA256SUMS.txt` 校验完整性

发版流程:推送 `v*` tag 自动触发 GitHub Actions 云编译并发布 Releases。

### 从源码编译:安装依赖

在 Linux 系统上,需要安装以下依赖:

1. `build-essential`:包含 GCC 编译器和其他构建工具
2. `sqlite3`:SQLite 数据库支持
3. `libsqlite3-dev`:SQLite 开发库

```bash
apt update
apt install build-essential sqlite3 libsqlite3-dev
```

### 编译

下载并解压源代码后,进入项目目录并运行 make 命令来编译:

```bash
make
```

此命令将编译源代码并生成 `imei_tool` 可执行文件。

## 使用说明

### 1. 启动交互式菜单

```bash
./imei_tool
```

交互式菜单提供以下选项:

#### 1. 导入 IMEI 前缀与型号
进入后先选择导入方式,任何导入都只在显式选择后执行(无自动导入):

| 选项 | 功能 |
|---|---|
| 1 | 手动输入:输入 IMEI 前缀(8 位)和设备型号 |
| 2 | 从 CSV 批量导入:输入文件路径,直接回车默认 `imei_prefix.csv` |
| 0 | 返回主菜单 |

#### 2. 列出已导入的前缀
分页显示数据库中全部前缀与型号(按前缀升序,每页 20 条):回车翻页,
`q` 提前返回,空库时明确提示。

#### 3. 产生随机 IMEI
根据已导入的 IMEI 前缀生成随机 IMEI。可以指定设备型号,也可以留空随机选择。

#### 4. 验证 IMEI
验证输入的 IMEI 是否有效。

#### 5. 离开
退出程序。

### 2. 命令行参数模式

#### 2.1 导入 CSV 文件

```bash
./imei_tool import imei_prefix.csv
```

CSV 文件格式(分隔符支持逗号 `,` 或分号 `;`):

```csv
12345678,model A
89012345,model B
56789012,model C
```

#### 2.2 生成 IMEI

```bash
./imei_tool generate 10
```

生成 10 个随机 IMEI。只为某个设备型号生成:

```bash
./imei_tool generate 5 "model A"
```

若未指定型号且库中没有任何可用前缀,程序会自动合成随机前缀:前 2 位从真实
RBI 国家码分配表(GSMA Reporting Body Identifier:01 美国、35 英国、86 中国、
91 印度、33 法国、45 丹麦、49-54 德国、44 英国)中随机抽取,后 6 位随机生成,
保证产出的 IMEI 国家码真实存在。指定了型号但库中没有该型号时仍会报错,
不会静默换成随机前缀。

#### 2.3 验证 IMEI

```bash
./imei_tool validate 123456789012345
```

检查输入的 IMEI 是否符合 Luhn 校验算法并且长度为 15 位。

#### 2.4 列出已导入的前缀

```bash
./imei_tool list
```

按前缀升序输出全部「前缀 型号」到标准输出(不分页,便于管道处理)。

#### 2.5 显示版本与退出码

```bash
./imei_tool version
```

命令的退出码有明确语义,便于脚本判断:

| 退出码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 运行失败:验证不通过、导入失败(含零条入库)、数据库错误 |
| 2 | 用法错误:参数缺失或无效、未知命令 |

## 注意事项

- **字符编码**:源码、提示文案与 CSV 均为 UTF-8。Windows 下程序启动时自动
  将控制台代码页切到 UTF-8(65001)并在退出时恢复(Ctrl+C 中断同样恢复);
  Linux/macOS 终端原生 UTF-8 无需任何设置
- **CSV 必须为 UTF-8 编码**:GBK/Big5 等其他编码的行会被拒绝并计入跳过
  (不静默入库乱码);UTF-8 BOM 自动剥离;超过 255 字节的行整行跳过(不截断)
- **CSV 行尾**:支持 LF 与 CRLF;CR(旧 Mac)行尾的行会被整行跳过并输出警告
- **IMEI 前缀格式**:必须是 8 位纯数字
- **设备型号**:标识设备的字符串,可以包含空格和其他字符
- **生成规则**:随机选择一个已导入的前缀,生成 6 位随机数字,最后通过 Luhn 算法计算第 15 位校验码(8 位前缀 + 6 位随机 + 1 位校验)
- **CSV 导入**:格式错误、编码非法或前缀不合法的行会自动跳过,导入完成时
  显示成功/跳过数量;因数据库错误(如只读、锁超时)未入库的行会输出警告及原因,
  全部失败时退出码为 1
- **导入原子性**:整个导入在单个事务中执行,中途失败或被中断(如 Ctrl+C、进程
  被杀)会整体回滚,不会留下半套数据
- **并发运行**:多实例同时运行时,数据库锁等待上限 3 秒,超时报错并说明原因
  (v1.0.1 及之前会立即失败且无原因)
- **重复前缀**:数据库有 UNIQUE 约束,已存在的前缀绝不重复写入;导入汇总
  分三类显示「新入库 / 已存在 / 无效跳过」,重复导入同一文件不会产生重复数据,
  菜单中重复导入会提示「该前缀已存在」
- **空库生成**:未指定型号且没有导入任何前缀时,自动合成真实国家码前缀
  生成;指定型号而库中没有该型号时,报错退出(退出码 1)
